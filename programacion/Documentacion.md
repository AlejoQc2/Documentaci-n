### JAVA INTRO
#### Qué es Java?
Java es un lenguaje de programación de alto nivel, orientado a objetos y multiplataforma, creado en 1995. Es desarrollado y mantenido
por Oracle y se utiliza para crear diferentes tipos de aplicaciones y sistemas informáticos.

#### Dónde se uiliza?
*Aplicaciones móviles.
*Aplicaciones de escritorio.
*Aplicaciones web.
*Servidores y videojuegos.
*Conexión con bases de datos.

### JAVA SYNTAX
#### SYNTAX
Cada línea de código que se ejecuta en Java debe estar dentro de una clase. El nombre de la clase siempre debe comenzar con una letra mayúscula. En nuestro ejemplo, hemos llamado a la clase Main.
#### Statements
Un programa informático está compuesto por una serie de instrucciones que la computadora debe ejecutar para realizar determinadas tareas. En los lenguajes de programación, estas instrucciones se conocen como sentencias y permiten indicar al compilador qué acciones debe realizar, como mostrar un mensaje en pantalla.

### JAVA OUTPUT
#### Print Text
El texto que se desea mostrar en pantalla debe estar escrito entre comillas dobles (" "), ya que estas permiten indicar al compilador que se trata de una cadena de caracteres y no de una instrucción del lenguaje Java.

#### Print Numbers
También es posible utilizar el método println() para mostrar números en pantalla. A diferencia de los textos, los valores numéricos se escriben directamente, sin necesidad de colocarlos entre comillas dobles, ya que Java los reconoce como datos numéricos.

### JAVA COMMENTS
#### Single-line Comments
Los comentarios de una sola línea en Java comienzan con dos barras diagonales (//). Todo el texto escrito después de estos símbolos, hasta finalizar la línea, es ignorado por el compilador y no se ejecuta como parte del programa. Se utilizan principalmente para agregar explicaciones o aclaraciones sobre el funcionamiento del código.
